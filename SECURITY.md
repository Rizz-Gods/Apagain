# Security Policy

## Scope

This project is evolving and is not security-certified. Security reports are welcome for vulnerabilities in the OTH codebase, including unsafe permission handling, credential exposure, policy bypasses, and unintended external actions.

## Reporting a vulnerability

Please do not publish exploit details in a public issue.

Use GitHub's **Private vulnerability reporting** feature for this repository when it is available. If it is not enabled, open a brief issue asking the maintainer for a private reporting channel without including sensitive details or a proof of concept.

Please include the affected version or commit, the impact, reproduction steps that do not expose real credentials or personal data, and any suggested mitigation.

## Response

The maintainer will review reports as capacity allows. Please allow reasonable time for investigation and coordinated remediation before publicly disclosing an issue.

Do not test suspected vulnerabilities against systems, accounts, or data that you do not own or have permission to assess.
